Art Sources
===========

The runtime art in this folder is derived from open-licensed sources and is
stored as BMP files for the current EasyX asset pipeline.

Character Art
-------------

- Source: Kenney Roguelike Characters pack
- URL: https://opengameart.org/content/roguelike-character-pack
- License: Creative Commons Zero (CC0)
- Derived files: assets/characters/char_1.bmp through char_4.bmp

Card and Icon Art
-----------------

- Source: Fantasy RPG Icons
- URL: https://opengameart.org/content/fantasy-rpg-icons
- License: Creative Commons Zero (CC0), as listed on OpenGameArt
- Derived files: assets/cards/card_1.bmp through card_8.bmp, assets/icons/*.bmp

Replacement Convention
----------------------

- Character art uses assets/characters/char_<character_id>.bmp
- Card art uses assets/cards/card_<card_id>.bmp
- UI icons use descriptive names under assets/icons/

Replacing one of these files changes the visual appearance without changing
the character or card rules stored in src_data/.
